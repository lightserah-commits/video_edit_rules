# 装飾ルール（テロップの種類・SE・ズーム・BGM）

カットと通常テロップが完成した後の「装飾」工程で、AIが次のことを決めるためのルール集。

- どの字幕を強調するか（強調の種類）
- どの保存スタイルのテロップに差し替えるか
- どのSEを、どのタイミング・どの音量で鳴らすか
- 寄る・引く（ズーム）か、何%にするか
- BGMを止めるか
- どこを図解にするか（`09_図解.md`）

工程の順番と、各工程で何をするかは `編集の依頼文.md` の「2. AIの進め方」（工程0〜12）。装飾は **強調・スケール縮小・SE → 図解 → BGM** の順に決める。

## ルールの一覧

最初に全部は読まない。どの工程で何を読むかは `CLAUDE.md` の「読むもの」と `編集の依頼文.md` の各工程。

1. このREADME
2. `00_上司ルールとの対応表.md`：上司の方法セットのどのルールを取り込んだか／そのまま読むか
3. `01_判断フロー.md`：強調の候補ごとに何を判断するか（前後まで読み、種類＝意味／感情・型・文言を決める。手順と実例）
4. `02_演出パターン.yaml`：発話の性質 → スタイル・SE・ズーム・BGM の対応表（本体）
5. `03_SEカタログ.yaml`：26種のSEの意味・音量・実例・ファイルの場所
6. `04_ズーム・BGM・テンポ.yaml`：倍率・BGMの止め方・テンポの目安
7. `05_アニメーション.yaml`：テロップの種類ごとの出方の動き（実測のキーフレーム値）
8. `06_テロップの大きさ.yaml`：強調テロップの文字の大きさ（スタイルごとの基本の大きさ、横幅は画面の90%まで、短い一言の倍率）。ツールが読んで自動で大きさを決める
9. `07_画面共有とワイプ.yaml`：画面を見せながら話す動画。音と映像の合わせ方、カメラと画面の切り替え、ワイプ（右上・画面幅の17.5%）、読み上げている所の赤枠、個人の画面のブラー
10. `08_カットと字幕の追加ルール.yaml`：上司の方法セットに加える、このチャンネルのカット・字幕・話者の決まりと、修正指示の受け方（ユーザー指示から）
11. `09_図解.md`：イラスト・札・見出しを組み合わせた図解。今は2本目の例を集めた段階（細かい決まりはこれから）
12. `素材/イラスト/イラスト一覧.yaml`：代弁（常識を引っ張る）や図解で使う人物・ものの絵。「役×気持ち」で選ぶ
13. `実例/みかみCH0726/events.csv`：実際の配置279件。迷ったら似た行を探す

## 別のプロジェクトを解析してルールを育てる

```
python3 tools/decoration_report.py 完成.prproj --out 実例/プロジェクト名
```

- 標準ライブラリだけで動く（Python 3.9）。33分のプロジェクトで数秒
- 通常字幕のスタイルは自動判定（全テロップの8%以上を占めるスタイル）。違う場合は `--base-styles "みかみテロップ,質問者テロップ"` で指定
- 出てきた `summary.md` を今回の実例と比べて、同じ傾向ならルールを確定、違えば `02_演出パターン.yaml` を更新する
- 並べる座布団と代弁は `python3 tools/plates_roleplay.py 完成.prproj シーケンス名 出力.json` で数字を取る（2026-09-26 に完成版・2本目で実施）

## まだ確認していないこと

- 実際の書き出し映像・音での確認（読んだのはプロジェクトの保存値）
- テロップの色・縁・サイズの数値（見た目は `~/Desktop/担当2/03_編集ルール定義/演出図鑑` と完成プロジェクトの見本クリップを正とする）
- 1本だけの観測なので、この編集者のクセとチャンネルの型の区別
