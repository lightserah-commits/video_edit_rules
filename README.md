# video_edit_rules（みかみCH の動画を AI が Premiere で編集するためのルールと道具）

AI への入口は `CLAUDE.md`（最初にやること・守ること・どこに何があるか）。進め方は `編集の依頼文.md`（工程0〜13）。話題からルールの場所を探す時は `索引.md`、いつ何を変えたかは `記録/変更履歴.md`。

## 装飾ルールで決めること

カットと通常テロップができた後の「装飾」の工程で、AI が次のことを決める（強調・スケール縮小・SE → 図解 → BGM の順。`編集の依頼文.md` の工程5〜7）。

- どの字幕を強調するか（強調の種類＝意味／感情）と、その文言
- どの型（保存スタイル）のテロップに差し替えるか
- どの SE を、どのタイミング・どの音量で鳴らすか
- 寄る・引く（ズーム）か、何%にするか
- BGM を止めるか
- どこを図解にするか（`ルール/09_図解.md`）

カット・字幕の追加ルール（`08`）と画面共有（`07`）もこのフォルダにある。上司の方法セットとの分担と違って見える点は `上司の資料/README.md`。

## 道具（tools/）

工程の順の一覧は `tools/README.md`。

## 素材（素材/）

- `SE/`：固定で使う SE 26種（元のファイル名のまま。中身が同じ重複ファイルは除いた）。中身は `ルール/03_SEカタログ.yaml`
- `BGM/`：メインテーマ、ダイジェスト用 BGM（`04` の bgm）
- `イラスト/`：2本目で使った人物・ものの絵24枚と、役×気持ちの表（`イラスト一覧.yaml`）
- SE・BGM の実ファイルをこのフォルダに入れたのは、AI がパスで確実に参照でき、長さ・先頭の無音・音量を測れるようにするため。音源の利用条件は元の素材のまま（社外に出さない）

## 完成した動画から学ぶ（ルールを育てる）

完成版の Premiere プロジェクトを受け取ったら、装飾の実例を追加して、ルールと比べる。違いがあれば、ルールの変更案としてユーザーに出す（確認をもらってから直し、`記録/変更履歴.md` に書く）。

```
python3 tools/decoration_report.py 完成.prproj --out 実例/<名前>
```

- 標準ライブラリだけで動く（Python 3.9）。33分のプロジェクトで数秒
- 通常字幕のスタイルは自動判定（全テロップの8%以上を占めるスタイル）。違う場合は `--base-styles "みかみテロップ,質問者テロップ"` で指定
- 出てきた `summary.md` を今の実例と比べて、同じ傾向ならルールを確定、違えば `ルール/02_演出パターン.yaml` などを直す案を出す
- 並べる座布団と代弁は `python3 tools/plates_roleplay.py 完成.prproj シーケンス名 出力.json` で数字を取る（2026-09-26 に完成版・2本目で実施）
- 図解は `ルール/09_図解.md` の冒頭の拾い方、カットは `実例/カット調査/カット調査.md` と同じ手順で比べる
- プロジェクトが無く完成動画だけの時は、`実例/実演お手本/scripts/`（画面の文字認識でテロップを拾い、色で種類に分け、出る瞬間を30fps のコマと波形で測る）で調べる。手順と結果は `実例/実演お手本/分析.md`（2026-10-02 実演のお手本2本）
