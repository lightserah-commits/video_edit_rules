## 工程3：カットと映像の選び方

| 道具 | 何をするか |
|---|---|
| `find_repeats.py` | 近くで同じ話をくり返している所の候補（同じ言葉が続く・文が似ている。`08` の remove） |
| `flow_table.py` | 字幕・問い・強調・図解・説明・カットを見る順に並べた一覧（考えずに分かるかを読む。`ルール/動画の土台.md`） |
| `find_silent_acts.py` | 黙って演じている所の候補（字幕の間の声の無い時間。言葉が途中で抜けている所を上に）を一覧と 0.5秒ごとのコマの画像にする |
| `find_laugh_gaps.py` | 笑い声・言葉の途中の間の候補（残している区間の中で、文字起こしに言葉が無い 0.5秒以上）を、切る点（大きさの谷）つきで一覧にする（`08` の cut.pauses.laugh_gaps） |
| `find_silence.py` | 残している区間の声の無い所を、文字起こしに頼らず声の大きさ（camera_env.npy）だけで探す。1.0秒以上は切る候補（図解の中も。残してよいのは最後の挨拶だけ）で、残っていれば終了コード1。0.5〜1.0秒は「溜めか読む」の一覧（`08` の cut.pauses.laugh_gaps・screen） |
| `find_fillers.py` | フィラーの候補の一覧。フィラーも書き起こす文字起こしを作り、残している所のフィラーを「声も切る／声は残す」に分け、切る区間（大きさの谷）と EXTRA_CUTS の行を付ける。`--mp4` で書き出しに残っている言いよどみを見る（`08` の cut.remove「フィラー（言いよどみ）」。2026-10-20） |
| `check_stray_words.py` | 字幕にも「切る」にも入っていない言葉の声（⑥）と、切ると決めた言葉の端の声（⑦）が残した区間に残っていないかを一覧にする（`08` の captions.base.check の⑥⑦。読んで決める。2026-10-19） |
| `wave_shape.py` | 間と語尾を秒数ではなく波形の形で見る（08 の pauses・no_chop.sound）：その録音の部屋の音の高さを測り、残す区間をつないだ時の平らな所のうち目立って長い物を坂まで詰める案（`--mode long`。`rule`・`all` もある）と、つなぎ目が語尾・言い出しの坂の途中で切れている所（tail・head＝戻す案）・笑いや声が重なる所（shaky）・戻すと次の語が入る所（chop）を出す。`--json` の cuts を EXTRA_CUTS へ。1025・1026 の手の直しで当てた（2026-10-28） |
| `check_cut_list.py` | カットの検査を1つの一覧にして、未処理が残っていたら止める（終了コード 1）。声の無い所・言葉の無い音・字幕に無い言葉・波形の形はここで動かし、フィラー・語尾・切れ端・音のブツッは結果を読む（無いか古いと止まる）。残す物は `_work/cut_keep.tsv` に理由。入りの間の数字も出す。`premiere_case/export.py` はこの結果が通っていない版を書き出さない（`08` の cut.before_handing。2026-11-04） |
| `cut_bench.py` | カットの答え合わせ：完成版2本の素材の範囲を AI に切らせ、お手本と文字ごとに比べて切り残しと切りすぎを出す（`--tl` で案件の手のカットも答えにできる）。カットのルールや頼み方を変える時に、頼みを書く時に読んでいない範囲で流す（結果は `実例/カット調査/答え合わせ_20261104/`。2026-11-04） |
| `listen_bench.py` | 音を聞ける AI の聞き分けテスト：完成版の公開された部分の切り口と、わざと崩した音を Gemini に聞き比べさせて当たる割合を出す。外部送信なので、動かす前に小川さんの OK を取る。無料枠は1モデル1日20回（結果は `実例/聞き比べ_20261104/`。細かい崩しは未測定） |
| `fast_forward.py` | 黙って PC を操作・待っている所を、カメラの早回しの mp4 にする（ルールへの反映は小川さんの確認の後） |

## 工程13：納品と片付け

|---|---|
