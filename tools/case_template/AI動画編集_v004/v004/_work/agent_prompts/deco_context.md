## 表の書き方（plan_v002.py が plan_parts/dNN_<表>.txt を読む）
- SCREEN：最初の字幕|最後の字幕|左上の札の文言|理由（上の「画面について」。Loom の間だけ）
- TAME：字幕ID|理由（オチ・ツッコミ・短い反応の前に間を 0.35秒残す。08 の pauses.keep_as_tame）。2列目に秒（例 1.5）を書くと、その秒だけ残す（顔・手で演じている所。08 の pauses.keep_face）
- EMPHASIS：字幕|パターン(P01〜P08)|SE|ズーム|BGM|種類(意味／感情)|文|理由|まとめる最後の字幕
  - SE は次の名前から：ピピ・cursor・キーン・キランッ・ピピ7・キッ・しゃん・クリック・決定・ドスッ・ポカン・ドン・シャーン・ピラリーン・グキッ・シャラーン・ドドン・ピコンッ・キラ・カカッ・キキッ・ピアノ・チーン・キラーー（03 の SE カタログの中身と同じもの）
  - ズームは「寄り120」「寄り125」「寄り130」「強い寄り150」「引き78」など（04 の zoom。**Loom の間・聞き手の字幕では付けない**）。BGM は止める候補なら「停止」
  - 文の中の半角の空白は、2行にする時の改行の位置（1か所）。文は字幕の切れ端を写さない（01 の「強調テロップの文言」）
  - 強調は、その字幕の頭から出る。**文の最初の言葉が、その字幕の最初に話している言葉になるように字幕を選ぶ**（01 の「出す時刻」）。字幕の頭に文に入れない前置きがあるなら、前置きの無い次の字幕から始めるか、前置きも含めた文にする
- SE_ONLY：字幕|SE|理由（通常字幕のまま SE だけ）。字幕の列を「ID@言葉」と書くと、その言葉の聞こえ始めで鳴らす
- PLATES：種類|項目|この字幕の終わりで消す|SE|理由
  - 種類「問い」：聞き手が話を正しい方向へ誘導する問い（02 の P11「問い」・08 の long_question）。項目は「字幕ID:Q: 問いの文」の1つだけ。要約しない・条件と主語を残す・先頭に「Q:」・2行に収めて1枚（行の区切りは ／）。消す字幕＝問いの最後の字幕。SE はピピ
  - 種類「並列」：同じ階層のもの（2〜3個）を挙げる所。項目は「字幕ID:文字;字幕ID:文字;…」（3つまで。青の札 T172〜T174。長い文字は切れるので1つ9字くらいまで）。SE は cursor
  - 種類「両立」：2つを同時に満たす話（02 の P11 の layout「両立」。横に2つ）
- ROLEPLAY：セリフ（字幕ID:文字:E003 を ; で区切る）|理由（P16 アホなふり：黒帯＋白い明朝）
- NOTES：字幕|文言|型|SE|理由|上下のずらし（01 の手順3 の説明。※用語の説明・※事実の補足・↑の一言。型は T132（※注釈。白い文字・ヒラギノ）、編集者のツッコミは T023。SE は決定（※）か空。文言は \r で2行まで）
