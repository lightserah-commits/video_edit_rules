## やること
1. 工程9 の検査の結果（checks_*.json・checks_log.txt）を読む。足りなければ RULES/編集の依頼文.md の工程9 のコマンドで回してよい（出力は V/確認/ の下に書く。V のほかのファイルは上書きしない）
2. 流れの表 flow.txt を頭から最後まで全部読む：①話が考えずに分かるか（つながり・指す言葉・前提が後から出る所・説明が足りない言葉）②強調・説明・問いの札・ボード・図解の文が元の発言（script_v003.txt）と合っているか・意味が変わっていないか・省略しすぎていないか ③同じ話のくり返し・迷い・言いかけが残っていないか ④CTA（1015プロジェクト・SEO1015）が分かりやすく出ているか
3. つなぎ目（joins_v003.tsv）を読む：切った後の「前の字幕 → 後の字幕」が通じるか（接続の言葉・指す言葉・話題の飛び）
4. 画像の一覧を全部見る：文字のはみ出し・重なり（強調と字幕・※と強調・座布団と顔）・右上タイトルの出し方（画面・図解・ズームの間は出さない）・画面の時のワイプと左上の札・誤字・画角の変わり目に前のテロップが残っていないか・冒頭ハイライト
5. 音は数字で見る（checks_log.txt の検査。BGM と声の差など、出ていれば）。耳で確かめる所は「小川さん」に分ける
6. **2回目の問題（E/v002/確認/problems_round2.json の who＝直せる の13件）が直っているかを1件ずつ確かめる**（E/v003/直し_v003.md に直し方。4 の決定・キラ・ポカンは「外した」のが直し）。直っていない物は問題として載せる。who＝小川さん の9件（14〜22）は小川さんに最後の OK でまとめて聞くので、同じ物をもう一度載せなくてよい（新しく見つけた小川さんの判断の物だけ載せる）
7. **画面の赤枠（07 の read_frame）**：赤枠の出る画像（名前に「赤枠」が入る物と、画面を映している所）を見て、話している所を囲んでいるか・空白や違う所を囲んでいないか・ワイプ・札・字幕にかかっていないかを確かめる
8. 問題を全部一覧に書く。1件ごとに「直せる（AI が直せる）／小川さん（判断が要る）」を分ける。2回目にも出た同じ問題（同じルール・同じ場所）には "repeat": true を付ける
