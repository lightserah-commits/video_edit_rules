## 台本の書き方（必ずこの形。CASE/v002/common.py の Script が読む。1行1つ）
- `u|字幕` … 区切り u の頭（u の最初の語の聞こえ始め）から出す字幕。u の声と、その後ろの「書いていない区切り」の声をまとめて1枚に出す
- `u+|字幕` … 区切り u の途中から出す字幕。字幕の頭の文字を u の文字起こし（chunk の4列目の〔 〕の外）の中から探して始まりを決める
- `u+語|字幕` … 字幕の文字が文字起こしと違う時（固有名詞・誤りを直した・フィラーを抜いた）は、始まる所の文字起こしの語（u の text に**そのまま含まれる**文字列。〔2回目〕の文字ではない）を「語」に書く
  - u の頭がフィラー（えー・あの・まあ・なんか）や表示しない接続語で始まる時は、`u+本文の最初の語|字幕` にする（フィラーの間は前の字幕を出したまま。08 の captions.base の filler）。ただし前の区切りがカットで、前に字幕が無い時は、そのフィラーごとカット（`x A..u/語`）に入れる
- `u-|` … 区切り u は文字を出さず、前の字幕を延ばす（フィラーだけの区切りなど）
- `u|∅（AIが編集した動画）` … 字幕を出さずに残す（切る方針3 の所だけ）
- 書いていない区切りは、直前の字幕にまとめたもの（その文字は直前の字幕に入れておく。2行に収まらないなら字幕を分ける）
- `x A..B|理由` … カット。A・B は「u」（その区切りの頭／終わりまで丸ごと）か「u/語」（u の中のその語の頭。語は u の text にそのまま含まれる文字列）
  - `x 5..7|理由` は 5・6・7 を丸ごと切る。`x 5/語..7|` は 5 の「語」から後ろと 6・7 を切る（5 の前は残る）。`x 5..7/語|` は 5・6 と 7 の「語」の手前までを切る（7 の「語」から後ろは残るので、その字幕は `7+語|…` で書く）
  - 理由は短く具体的に（例「段取り：撮影の相談」「くり返し：12〜14 と同じ結論」「聞き手の相づち」「言いかけ：78 で言い直している」「待ち」「空耳」「強い言葉：…」「キーワードの言い直し（三上さんと違う）」）
- `@` … 字幕の頭に付けると聞き手（創太くん）の字幕。付けなければメイン（三上さん・こういちさん）
- `／` … 2行にする所（1行17字まで・全角1・半角0.5。2行まで。3行にしない）
- `#` で始まる行はメモ（読まれない）。塊の最初に `# 塊N（区切り a〜b）` を書く
- 句読点（、。）は出さない。？！は使ってよい。フィラー（えー・あのー・まあ・うーん・えっと）は出さない
- 書く順は区切りの番号順。カット x は、切る区切りの位置に書く
- 例：
  ```
  0|どうも アドネスの三上です
  1+最近|@最近 AIの自動編集っていうのが／めちゃくちゃ話題で
  x 5..9|段取り：撮影の相談
  10|うちのYouTubeの編集は／「編集して」で終わるんですよね
  ```

## 決め方
- まず担当の区切りを全部読み、話のまとまり（フリ → 本題 → 反応・オチ）をつかんでから、08 の cut（remove・keep・no_chop.flow）で切る所を決める。理由はカットの行に書く
- 同じ話のくり返しは一番伝わる1回だけ残す（08 remove の1つ目）。こういちさんは同じ文を2回ずつ言い直していることがとても多い（例「直近だと結構1万再生超える動画」→「直近だと1万再生を超えるような動画が出たりだったりとか」）。後ろの言い方（言い切れている方）だけ残す。ただし条件・否定・問いと答え・因果を担う所は残す。迷ったら切る側にして理由を書く
- 迷い・言い直し・言いかけ・思い出せない所・撮影の段取り・聞き手の相づちは切る。CTA（プレゼント・公式LINE の案内・キーワード）は上の 6 のとおり
- 切った後に「前に残した一文 → 後に残した一文」を読んで、つながるか確かめる（接続の言葉・指す言葉・話題の飛び）。引っかかったら塊ごと切るか戻す
- 字幕は話した言葉に近く（直すのはフィラー・言い直し・音声認識の誤り・固有名詞の表記だけ）。主語・目的語が抜けて初心者に何の話か分からない所は（ ）で補う（08 の supplement。言っていない主張は足さない）。画面で「これ」「ここ」を指している所は、画面が映るので補わなくてよい（Loom の間はずっと画面が映る）。カメラだけの所で「これ」が何を指すか分からない所だけ（ ）で補う（08 の this_that）
- 字幕の区切りは意味と息のまとまり（08 の captions.segmentation の R1〜R9・layout）。1行17字・2行まで。改行は節の切れ目か助詞の後ろ、「〜の」を行末に残さない、引用は「って」から下の行
- 2秒以上声が無い所（chunk の6列目が 2.0 以上）で、言葉が途中で抜けている所は、カメラで顔・手で演じていないか気をつける（08 の pauses.keep_face。迷ったら残して doubts に書く）。Loom の間の無言は、画面の操作（待ち・探しもの）が多い
- 書き終えたら、担当の区切りで「どの字幕にも入っていない・カットにも入っていない区切り」が無いか、区切りの番号を頭から順に確かめる。`~/Desktop/video_edit_rules/env/bin/python CASE/v002/_work/check_part.py CASE/v002/script_parts/pNN.txt a b`（a・b＝担当の最初と最後の区切り）を流して、エラー（E）を0にする

## 出すもの
- CASE/v002/script_parts/pNN.txt に台本を書く（NN＝塊の番号を2桁。フォルダはある。ほかの塊のファイルには触らない）
- CASE/v002/script_parts/pNN_notes.json に返す値と同じ中身を書く
- 返す値（schema）：書いたファイル・字幕の枚数・カットの数・大きく切った所（範囲・秒・理由）・直した音声認識の誤り・仮に決めた話者・冒頭ハイライトの候補・初心者がつまずきそうな言葉（説明を足す候補）・話題の区切り（区切りの範囲と一言の見出し）・強い言葉として切った所（strong_words）・判断に迷った所（doubts）
