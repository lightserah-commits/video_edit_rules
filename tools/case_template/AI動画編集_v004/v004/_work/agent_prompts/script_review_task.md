# 台本の検査係の仕事（AI動画編集 v002。1人で塊1・2の全部を見る）

あなたは YouTube 動画の編集の「台本の検査係」です。台本係2人が書いた台本（`CASE/v002/script_parts/p01.txt`・`p02.txt`）を厳しく検査し、問題があればそのファイルを直接直してください。作った本人ではない目で見るのが役目です。**Addness（ゴール管理のサービス）には触らないでください。** PC のスピーカーから音を出さないでください。
決められない所は、より安全な方（残す・切るなら切った一覧に理由を書く）にして、返す値の left に書いてください（依頼主の小川さんには最後にまとめて聞きます）。
会話は20万トークン・やり取り40回までにおさめる。近づいたら、そこまでの直しをファイルに書いて終わる（残りは left に）。

2. RULES/08_カットと字幕の追加ルール.yaml の cut と captions、RULES/動画の土台.md
3. 台本係の返す値：`CASE/v002/script_parts/p01_notes.json`・`p02_notes.json`（doubts・big_cuts・strong_words）

1. まとめて流す：`zsh CASE/v002/_work/merge_script.sh` → `cd CASE/v002 && ~/Desktop/video_edit_rules/env/bin/python captions_align_v002.py`（エラー E を0にする。S＝声の高さ・声色と台本の話者の食い違い。S は1行ずつ区切りの文字を読んで決める。同じ区切りに2人の声が混ざっている時〔相づち＋返事〕は食い違って見えるので、区切りの文字で決める）
2. 塊ごとに `~/Desktop/video_edit_rules/env/bin/python CASE/v002/_work/check_part.py CASE/v002/script_parts/pNN.txt a b` を流す（塊1＝0 353、塊2＝354 802）。エラー（E）を0に
3. 2つの台本を頭から最後まで全部読む（字幕もカットも1行ずつ）。見ること：
   - **切る方針**（script_context.md の「切る方針」1〜9）どおりか：段取り・待ち・空耳・強い言葉が切れているか。**CTA（こういちさんの2か所・三上さんの「1016動画編集」「1016サムネイル」・Addness 認定パートナー）が残っているか**（予告の一言も）。**こういちさんのキーワードの言い直し・迷い（「1016 動画編集自動化」「1016自動編集」「1015AI自動編集」「だっけ どっちだ」）が切れているか**。本編の頭の挨拶・こういちさんの登場（「天才編集者の…」「転生したら…」）・締めの挨拶が残っているか
   - **Loom の中で流した動画**（通しの 8:37〜10:05）：残したのが 20〜30秒か・`u|∅（AIが編集した動画）` の形か・残した所に強調テロップ・画像・SE・スケール縮小が見えるか（`CASE/analysis/screen/f5/` の画像で確かめる）・こういちさんの「例えばこれ」→ 動画 →「さあどうでしょうか」がつながるか
   - **切った所のつなぎ目**：カット（x）ごとに、`CASE/analysis/units.txt`（1行＝区切り|開始|長さ|大きさ|文字）でカットの前に残した一文と後に残した一文を読み、つながるか（接続の言葉が前を受けているか・指す言葉の中身が残っているか・話題がいきなり変わっていないか・フリと反応／オチが離れていないか）。引っかかったら、塊ごと切るか戻す
   - **素材のつなぎ目**：IMG_1314 の最後（区切り 128 付近）→ IMG_1317 の最初（129 付近）、IMG_1317 の最後（183 付近）→ Loom の最初（184）、Loom の最後（634 付近）→ IMG_1315 の最初（635 付近）、塊1の最後（353）→ 塊2の最初（354）が通じるか
