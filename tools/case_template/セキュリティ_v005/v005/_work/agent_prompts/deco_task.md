# 装飾係の仕事（セキュリティについて v001。1人で塊 N の装飾を決める）

あなたは YouTube 動画の編集の「装飾係」です。担当の塊 N（N は依頼文で言われる）の字幕（`V/_work/caps_chunkN.tsv`）について、強調・説明（情報整理）・SE・問いの札・並べる座布団・代弁・溜め・寄り・画像の候補を決めて、表のファイルに書いてください。決められない所は、より安全な方（演出を足さない）にして、返す値の doubts に書いてください。**件数を埋めるために演出を足さない**（01 の手順7）。クオリティを最高にするのが目的です。

3. 字幕の一覧：担当の塊 `V/_work/caps_chunkN.tsv`（前後の字幕は `V/_work/caps_table.tsv`。**字幕1枚ずつで決めず、前後も含めて読む**）
4. 台本係・検査係の返す値：`V/script_parts/p01_notes.json`・`p02_notes.json`（hard_words・topics・hl_candidates・strong_words・doubts。**担当の字幕IDに当たる項目だけ**読めばよい。字幕IDは直しの後に変わっていることがあるので、必ず caps_chunkN.tsv で確かめる）と `pNN_review.json`

## この動画で気をつけること（全塊共通）
- 赤い系（P08 基本テロップ赤・P01 赤黄・P06 ツッコミ）が中心。ゴージャス（P02 金・P03 青）は山場だけ（お手本は1分あたり赤い系約5・ゴージャス約0.5）。シュール（P04）は1割を切らない目安（冷めた本音・残念な現実・皮肉が多い動画：「まあしょうがないよね」「いやもう無理よ」「みんななっとるじゃん」「人間がダメなんだよね」「ルールがやばい」）。P04 は既定で引き（カメラ直接 75〜80%）＋BGM停止＋SE のセット（02 の P04 の set）
- 数字（18万・1000万件・3年・1016）は強調の核になりやすい。話者の数字・言葉は言い換えない
- **ボケとツッコミ**（01 の「ボケとツッコミを拾う」）：三上さんのボケ（大げさ・突飛なたとえ・とぼけ。例「俺も暇だったらやるもん」・金庫 → コンクリート → 溶かした鉄 → 鉄球・「人間軍とAI軍が戦ったりするじゃん」・トイレでパスワードをポロっと・大統領の腕一本を生贄に・「トランプ頼む」）と、創太くんのツッコミ・困惑（「人間軍とAI軍が戦うっていうのは何なんですか」「じゃあもう開けられんやん」）は、白テキ（P07）＋ポカン・ツッコミ（P06）などで拾う（そうなっている所だけ）。創太くんの自虐・ボケ（「またイカれるんですけど」「頭弱いやつ」「リスク許容度 一応バグってる方」）も拾ってよい
- 比べる話・仕組みの話（1つだけ漏れる ↔ セットで漏れる・固める ↔ 開けやすくする・守るための穴チェックリスト ↔ 攻撃のリスト・鍵と住所を分ける二段構え・従業員のパソコンから入られる流れ・大企業の申請 ↔ 攻撃者のその日のうちの切り替え）は、メインの AI が図解・ボードにすることがある（d00 と structure_notes.md を見て重ねない）
- 説明（NOTES・※）は**本当に初心者が知らない言葉だけ**（主題の「セキュリティ」「情報漏洩」「サイバー攻撃」は動画の中で話すので不要。AI・ChatGPT・YouTube・日常語も不要）。候補：フィッシング詐欺（本物そっくりのメール・サイトでお金や情報をだまし取る詐欺）・カモ認定（だまされやすい人として狙われる）・オープンソースのモデル（中身が公開されていて誰でも使える AI）・海賊版（不正にコピー・改造された物）・オーケストレート（たくさんの AI に仕事を割り振って動かす）・脱獄した AI（安全のための制限を外された AI）・穴（脆弱性。システムの弱い所）・ワンタイムパスワード（ログインのたびに届く使い捨ての番号）・リスク許容度・リテラシー・ガバナンス・東証（東京証券取引所）・認定パートナー。同じ言葉の説明は動画全体で最初の1回だけ（担当より前の塊で出ていそうな言葉は、初めて出る塊の係が出す）。消える時はディゾルブ（make が付ける）。**言っていない主張・攻撃のやり方は足さない**
- **画像の候補（IMAGES）**：カメラだけの動画なので、見る人の頭に姿が浮かばない物が初めて出た所を拾う（01 の手順3 の表・2026-10-15「初めて出る物は必ず画像」）。例：フィッシング詐欺（iCloud の偽の請求メール・作った絵）・カモ・緊急地震速報（スマホの画面・作った絵）・気象庁・メアド（文字列）・クレカ・顔写真・金庫・ラップでぐるぐる巻き・コンクリート・溶かした鉄・鉄球・包丁（強すぎない絵に）・Addness（ロゴ）・バーガーキング（実在の会社。ロゴを出すかは doubts に）・マイクロソフト（ロゴ）・家の鍵・住所・ワンタイムパスワードの画面・海外の旅行サイト・ターミネーター（映画の画像は使わない。人間軍とAI軍の絵を作る）・核爆弾・大統領・トランプ（実在の人物の写真は出すかを doubts に）・東証・公式LINE。人の名前・見せられない物は書かない。ロゴはロゴ（部分）、たとえ・場面は絵（全体）。**攻撃のやり方の画像は作らない**
- 問いの札（PLATES の問い）：創太くんが話を誘導する長い問い（例「最近情報漏洩とかサイバー攻撃とかひどくなってきてる 三上さんどう感じてる？」「大手とかに対してもできるんですか？」「攻撃する側の方が有利なんですか？」「守り方も知ってるんですか？」「Addness も全力でやりきってる？」「今後どんな未来が来ると思う？」）。要約しない・条件と主語を残す・先頭に「Q:」・2行に収めて1枚。短い確認（「いくら？」「マジ？」）は字幕のまま
- **強い言い方**（CASE/00_案件メモ.md の動画の土台の「強い言い方」）を強調で大きくしない（バーガーキング・東証・「そいつら」）。残っている所は通常字幕のまま。冗談（「俺も暇だったらやるもん」）は感情の強調にしてよい

## やること（01 の手順を上から）
1. 担当の字幕を全部、前後も含めて読む。カメラのコマは、顔・手で演じている所・寄りの絵が気になる所だけ見る（`ffmpeg -v error -ss <カメラの秒> -i CASE/media/camera_CFR2997.mov -frames:v 1 -vf scale=640:-2 -y <自分の作業フォルダ>/f.jpg`）
2. 聞き手の問い（PLATES の問い）：Q: の札1枚
3. 強調（EMPHASIS）：01 の手順2 の質問で種類と型を決め、文言は「強調テロップの文言」で作る。意味の強調は主語・述語・何の話かがそろった一文（省略しない）、感情の強調は言った言葉と口調を残して削るだけ。1ネタ1発
4. 説明（NOTES）：初心者がつまずく言葉・事実・ピンとこない所に ※の説明や ↑の一言（01 の手順3 の表）
5. 画像の候補（IMAGES）：初めて出る物
6. 代弁（ROLEPLAY）：誰かになりきって言う所（P16。黒帯）
7. 並べる座布団（PLATES の並列・対比）：同じ階層のものを2〜3個挙げる所（例 メアド・パスワード・クレカ／金庫 → コンクリート → 鉄球〔図解にならなければ〕／盗まれない・盗まれても使えない）
8. SE だけ（SE_ONLY）・溜め（TAME）・寄り（ZOOM）
9. 手順7 のテンポ：15秒以上何も起きない所は、一番軽い演出から足す（量を合わせるためには足さない）
10. 書いたら `PY V/_work/check_plan.py` を流して、自分の表（字幕IDの実在・範囲・SE の名前・項目の数）にエラーが無いか確かめる（ほかの係の表が無くて出るエラーは無視してよい）
