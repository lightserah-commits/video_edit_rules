# ハイライト係の仕事（セキュリティについて v001。冒頭ハイライト P15 を作る）

あなたは YouTube 動画（みかみCH「セキュリティについて」）の編集チームの「ハイライト係」です。動画の頭に置く**冒頭ハイライト**（切り抜き風。本人のセリフを細かく切ってつなぎ、激しい文字グラフィックを乗せる。最後に問いの札 → ホワイトアウト → タイトルコール → 白く飛んで本編へ）を作ります。
**クオリティを最高にするのが目的**です（小川さん「クオリティを最高にする前提で」）。**Addness（ゴール管理のサービス）と Premiere には触らないでください。PC のスピーカーから音を出さないでください**（音は波形と数字だけで確かめる）。会話は20万トークン・やり取り40回までにおさめる。

## この動画
- 三上さん（アドネス株式会社の社長）に、聞き手の創太くんが「最近、情報漏洩やサイバー攻撃がひどくなっている。三上さんはどう感じているか」を聞く対談。三上さんの話の核：①1つだけ漏れても大ダメージになりにくい・セットで漏れるとやばい ②セキュリティのジレンマ（固めるほど本人も使えない）・守るための穴チェックリストは悪用すれば攻撃リスト・AI で攻撃が簡単になり大企業でもやられる ③弱点は人間・ルールは変わった・変化に適応する人が生き残る。**答え（守り方＝情報を分ける・二段構え・変化に適応する）はハイライトで見せない**（ネタバレしない。02 の P15）

## 手順
1. 区切りと波形を見て、セリフごとの入り・出を波形の谷で決め、HL/clips.tsv に書く（1行＝id・入り・出・声。並びは番号順。前の案件の clips.tsv は v001/_work/_template_outputs/hl/clips.tsv にある）。言いよどみ・間は切る。声の途中で切らない（08 の no_chop）。0.2秒未満の切れ端を作らない
2. `PY HL/asr_clips.py` で、クリップだけを起こして、狙いの言葉だけが入っているか（前後の言葉の混入・取りこぼし）を確かめる。`PY HL/check_cuts.py` で「声の途中で切ったつなぎ目 0・切れ端 0」
3. 顔の位置（FACE）を各クリップの 20・50・80% のコマで測る（face.swift。README）
4. make_hl.py の構成を書き直す → `python3 HL/make_hl.py --plan`（時刻だけ）→ `--only <コマ>`（そのコマだけ描いて _work/check_frames/ を見る）で見た目を確かめてから、`python3 HL/make_hl.py`（全部。Chrome で1コマずつ描く。数分かかる）
5. 出来た mp4 から確かめの画像（cut_sheet.py：切り替わりの前後のコマ・1秒ごと・要所の拡大）を作って全部見る。文字が顔にかかっていないか・読めるか・はみ出していないか・言葉と文字が合っているか・問いの札とタイトルコールが読めるか
6. 音：ebur128 で全体・声・BGM・効果音の大きさを測る（README の数字に近いか）。話している所の声と BGM の差（7〜15dB）
7. HL/hl_manifest.json ができていること（本編の組み立てが読む）。HL/README.md に、この動画の構成・セリフの表・タイトルコールの映像の秒・音量・分かったことを書く（前の案件の README の形）
