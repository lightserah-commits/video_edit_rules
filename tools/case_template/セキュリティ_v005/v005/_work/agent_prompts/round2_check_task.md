## やること
1. 工程9 の検査の結果（checks_*.json・checks_log.txt）を読む。足りなければ RULES/編集の依頼文.md の工程9 のコマンドで回してよい（出力は V/確認/ の下に書く。V のほかのファイルは上書きしない）
2. 流れの表 flow.txt を頭から最後まで全部読む：①話が考えずに分かるか（つながり・指す言葉・前提が後から出る所・説明が足りない言葉）②強調・説明・問いの札・ボード・図解の文が元の発言（script_v002.txt）と合っているか・意味が変わっていないか・省略しすぎていないか ③同じ話のくり返し・迷い・言いかけが残っていないか ④CTA が分かりやすく出ているか ⑤カメラだけの所で、見る人の頭に姿が浮かばない物が初めて出る所に画像か図解があるか（動画の土台.md の1・01 の手順3）⑥15秒以上何も起きない所（01 の手順7。足す根拠ではなく見直しのきっかけ）
3. つなぎ目（joins_v002.tsv）を読む：切った後の「前の字幕 → 後の字幕」が通じるか（接続の言葉・指す言葉・話題の飛び）
4. 画像の一覧を全部見る：文字のはみ出し・重なり（強調と字幕・※と強調・座布団や画像と顔）・右上タイトルの出し方（図解・画像・ズームの間は出さない）・誤字・画角の変わり目に前のテロップが残っていないか・冒頭ハイライト・図解の読みやすさと言葉との合い方・最後の挨拶（手を振る所）が残っているか
5. 音は数字で見る（checks_log.txt の検査。BGM と声の差など、出ていれば）。耳で確かめる所は「小川さん」に分ける
6. 問題を全部一覧に書く。1件ごとに「直せる（AI が直せる）／小川さん（判断が要る）」を分ける。AI が決めたと 00_案件メモ.md に書いてある所（受付の項目・タイトルコール・合言葉・強い言い方の扱い）は、問題でなく「小川さんに確かめる」に入れてよい
