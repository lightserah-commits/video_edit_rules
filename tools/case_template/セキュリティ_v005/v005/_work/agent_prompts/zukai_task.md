## 手順（図解ごと）
1. 時刻を調べる：`python3 RULES/tools/zukai/tl.py --ver V words <最初の字幕ID> <最後の字幕ID>`（言葉ごとの聞こえ始めのコマ）。start_f＝最初の字幕の開始、end_f＝最後の字幕の次の字幕の開始（含まない）が基本
2. 絵コンテ（言葉 → 部品 → コマ）を diagram.json の story に書き、page.html を書く（README の手順。部品の出るコマ＝絶対のコマ − start_f）。ワイプ：`"wipe": {"show": true, "crop": [460, 30, 1440, 810]}` から始め、previews で三上さんの頭・手が切れていないか見て直す
3. `python3 RULES/tools/zukai/make_zukai.py --ver V <KEY> --check`（採寸・注意）→ `python3 RULES/tools/zukai/make_zukai.py --ver V <KEY>`（描く。Chrome。数分）。止まる時は `run_zukai.py`。**ほかの図解係も同時に描いているので、1つずつ流す**
4. `V/zukai/out/<KEY>/previews/` の画像を全部見る（読めるか・重ならないか・言葉と合うか・ワイプに部品がかかっていないか・画面の端から 40px 以上・字が大きいか）。直して描き直す（作り直しは `--name=auto`）
5. 確かめの一覧の画像（1015 の sheet_v007.jpg のような、時刻・字幕・見せていることを並べた物）を `V/zukai/out/<KEY>/sheet_v001.jpg` に作る（make_zukai.py の previews を並べる。道具が無ければ PIL で並べる）
