# 冒頭ハイライトの作り方（環境設定について v001 `hl/`。2026-10-03）

astra v007 の冒頭ハイライト（`0928 astra実演/edit/v007/hl/` 下書きB）を写して、中身をこの動画用に作り直した。02 の P15。

- 指示（小川さん、astra のとき）：「オープニングではなくハイライト」「切り抜きに激しい文字グラフィック」「20秒ぐらい、ホワイトアウト→タイトルコール→ホワイトアウト」「文字起こししすぎ。引きを作るように要約、前後が繋がる形に」
- 構成（**23.59秒・707コマ**・11カット）：AI好きほどムダだらけ → 流行りの Orca・Obsidian → ガチでいらない → 中身はただのメモ → しかも毎日腐っていく → じゃあ年商25億の社長は？ AIの「スキル」ほぼナシ → やってるのは環境構築だけ → AIが勝手にまた動き出す → ヤバくない？ → しかも社長と同じ環境がワンタップ → 「じゃあ、一番大事な環境設定とは？」→ ホワイトアウト → タイトルコール「年商25億AI社長の AI環境設定 全公開」（2.6秒・BGM なし・シャーン→指鳴らし）→ 白く飛んで本編へ
- タイトルコールの映像：カメラ 577.0〜579.6秒（顎に手を当てて画面を見て考えている。声なし 575.4〜582.7）。42:10〜46:54 の声なしは席を立っていて使えない

## 作り方

- `python3 make_hl.py`（全部・約1分）／`--plan`（時刻だけ）／`--only 15,60,...`（そのコマだけ `_work/check_frames/` に描く）
- `make_hl.py`：並び（ORDER）・場面の寄り（顔の位置 FACE は `_work/facedet`＝Mac の顔検出）・文字（声の区間に合わせて1字ずつ）・図形・光・効果音 → `hl.js` → 背景のコマ（`_work/bg/`）→ `render.mjs`（Chrome 4本で `page.html` を1コマずつ JPEG）→ 音 → 書き出し
- `page.html`：astra の描き方に、この動画の図形を足した（`tools` 道具のカードと赤い×、`memo` 付せんが腐る、`gauge` スキルのゲージが落ちる、`layers` 環境の層が積み上がる、`pill` 再開の札、`tapbtn` ワンタップのボタン。`chat` は見出しの名前を変えられるようにした）
- 音：声は話している所の大きさを −27dBFS にそろえる（クリップごとに +4.4〜+11.5dB）。BGM はダイジェスト用 −15dB、声で下げる（サイドチェイン）、「ヤバくない？」の間（H8 の終わり〜H10 の始め）は止める。効果音は 素材/SE と ffmpeg で作った音（`_work/sfx/`）
- 確かめの画像：`check/cuts_sheet.jpg`（切り替わりの前後のコマ）・`check/要所_1秒ごと.jpg`・`check/要所_拡大.jpg`（`_work/cut_sheet.py`）

## 分かったこと

- この案件のカメラは 42:10〜46:54（2530〜2814秒）で席を立っている。タイトルコールの「声なしで考えている絵」は 9:35〜9:42（575〜582秒）
