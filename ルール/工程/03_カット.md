# 3. カットと映像の選び方

- 決まりは `08` の quality_reference と cut（考え方 → 2段階 → 切るもの → 残すもの → つなぎ目 → 話のつながり → 間 → 切れ端 → 並べ替え → 尺の変更）。動画の型と見る人は `ルール/動画の土台.md`
- 字幕を頭から最後まで読んで本筋をつかんでから、切る種類を順に探す（`08` の stages の②）：塊で切る（1人で読む。動画を作る話・見る人についてのコメント・雑談などはおすすめどおりに切り、切った塊の一覧を工程11 で見せる）→ 1文だけ切る（話題ごと）→ 細かい中身（区切りごとの台本係）→ 最後に keep の「説明の本体」を読み直す。Addness の型では 3a・3b・3c
- くり返しの候補は `tools/find_repeats.py`（工程9）を読む。すぐ続けての言い直しは1回にし、離れた所の同じ種類の例の2つ目以降は切り、話が進んでいる2回目は説明の本体として残す（`08` の remove・keep）
- **言葉の無い音（息・笑い・小さい声）は、毎回 `tools/find_laugh_gaps.py` の候補を全部読んで、切るか残すか（理由）を決める**（`08` の pauses.laugh_gaps。動かしていない版は基礎品質の合格にしない）。カットを組んだら `tools/check_stray_words.py` で、字幕にも「切る」にも入っていない言葉の声・切ると決めた言葉の端が残っていないかを見る（`08` の captions.base.check の⑥⑦。2026-10-19）
- **フィラーは、カットを組んだら毎回 `tools/find_fillers.py --ver` の候補を全部読んで、声も切る物を決める**（`08` の remove「フィラー（言いよどみ）」。言いよどみ・三上さんの文の頭とつなぎ目の「あの」・つなぎ目に接する「やっぱ」「まあ」は声も切り、話し癖と「はい」は残す。今の文字起こしにはフィラーがほとんど出ないので、この道具を動かさないと見えない。2026-10-20）
- **カットを組んだら、`tools/check_cut_list.py --ver "<edit/vNNN>" --before-build` で検査を1つの一覧にし、未処理を0にしてから工程4 へ進む**（切るか、残す理由を `_work/cut_keep.tsv` に書く。`08` の cut.before_handing。2026-11-04）
- 依頼の尺より長い時だけ、説明の細部と長い1つ目の例を2段目で切る。尺の指定が無い動画と尺に収まっている動画では残す（`08` の stages の③。2026-11-04）
- 元の順番のまま並べると話の論理がおかしくなる所（同じ具体の話をもう一度しているように見える・前提が後から出る）を、ここで先に探して直す（`08` の reorder.logic_check。`tools/flow_table.py`）
- 話の途中で2秒以上黙っている所は、`tools/find_silent_acts.py` の一覧とカメラのコマを見て、顔・手で演じている所は切らずに残す（`08` の pauses.keep_face。見せ方は `02` の P18）
- 画面を見せる動画は `07`：カメラと画面の選び方（switching）、両方置く（both_tracks）、ワイプ（wipe）、実演の札（demo_label）。ぼかしは AI からは入れない（blur。候補の一覧を見せるだけ）
- 途中の版から（B）：カットを変えない約束なら触らない。戻す・足すのは言われた所だけ（例 画面共有装飾の中盤の CTA を戻した v001）
