# 8. 組み立て（新しい版のフォルダ。前の版は上書きしない）

基本は「**部品集（見本集の軽い版）のコピーの中で、完成版の実物を型IDから部品ごと複製し、文字だけ変える**」（`tools/reproduce.py`。使い方は `見本/README.md`、型は `見本/型一覧.md`）。図形・位置・エフェクト・アニメーション・SE の音量まで完成版と同じになり、Premiere で文字も直せる。画面解説 v006〜v008・画面共有装飾 v002・ワークの完全解説で使った。

| 何を | どう置くか | 使うもの |
|---|---|---|
| カット・声・カメラ／画面・ワイプ・BGM | 土台の FCP7 XML（`build_vNNN.py`）を、Premiere で部品集のコピーに読み込んで保存 | `_work/place*.py`（Premiere） |
| 通常字幕・強調テロップ・札・見出し | 型ID（T###）で複製して文字を変える。通常字幕は T001・T003。強調の文字は plan に書いた文（字幕の番号だけで済ませない。無ければ止める）。大きさは自動（06。代弁のセリフ T009 は `pattern="P16"`） | `Library.add_telop` |
| 画面効果（寄り・黒帯・図解の土台・ぼかし） | 型ID（E###）で複製。引きは E002 を使わず、カメラ直接（下の行・`04` の zoom） | `Library.add_effect` |
| SE | 型ID（S###）で複製。開始＝担当するテロップの開始フレーム（03 の rules） | `Library.add_se` |
| カメラのズーム・ブラー・クロップ | クリップにモーション・効果の部品を複製して付ける | `tools/native_prproj.py` |
| 画像・イラスト・赤枠 | Premiere で静止画として読み込んで置く | `_work/place*.py` |
| ディゾルブ（右上タイトルの最初・※注釈の終わり） | プロジェクトに直接書く（Premiere の QE の addTransition は使わない。見本から複製したクリップに古いディゾルブの参照が残っていて、トラックによって失敗・違う位置に付く） | `make_vNNN.py` の最後で `Prproj.add_dissolve`（手本 `tools/dissolve_template.xml`） |
| 確認の画像 | Premiere | `tools/premiere_case/finish.py`（時刻の一覧は `review_jobs_fixed.py` など。README） |

- 素材から（A）：`python3 tools/build_parts.py --case-copy "<案件フォルダの絶対パス>/edit/vNNN/<案件>_vNNN.prproj"`（例 `"$HOME/Desktop/みかみ案件依頼書/0928 astra実演/edit/v008/astra_air_v008.prproj"`。video_edit_rules で打つので、案件の .prproj は絶対パスで書く。相対で書くと video_edit_rules の中を指して止まる）で部品集（`見本/テロップ部品集.prproj`）を `edit/vNNN/` にコピーして案件のプロジェクトにし、基礎の XML（カット・声・BGM）を Premiere で読み込んで保存し、閉じる。`--case-copy` は素材をこの Mac の `素材/` に向け直す（Air と iMac でユーザー名が違っても見つかる）。部品集が見本集より古い・素材が欠けている・video_edit_rules の中を指した時は、何も書かずに止まる。`_work/place*.py` の中で見本集を直接コピーしない
- 途中の版から（B）：まず `build_parts.py --case-copy "<案件フォルダの絶対パス>/edit/vNNN/_work/部品集_取り込み用.prproj"` でこの Mac 向けの部品集のコピーを作り、起点のコピーに、Premiere でそこからシーケンス「テロップ見本集」を取り込む（`app.project.importSequences(そのパス, ["c791a6f1-ea06-4f32-9647-b21aefd7fef2"])`。シーケンスの ID は見本集と同じ。先に、起点に入っている古い「テロップ見本集」の名前を変える。）。案件のプロジェクトに入っている見本集が古いと新しい区画の型が使えないので、最新版を取り込む。部品集から取り込むのは未確認（2026-10-03）：最初に使う時に、取り込んだシーケンスのクリップが 251・素材がオンラインかを確かめる
- どの段に置くかは `02` の output_tracks（V1〜V11・A1〜A5。図解があれば V12 から上も用意する）。案件で変えた時は `00_案件メモ.md` に書く
- 並べる座布団（P11）・聞き手の問い・代弁（P16）の置き方（段・出す時刻・消す時刻・位置）は `02` のそれぞれのパターン
- 版ごとにスクリプトを分ける（前の版のフォルダをコピーして直す）：
  1. `plan_vNNN.py`：5〜7 の判定 → `decoration_plan.csv`。強調（P01〜P08）には、種類（意味／感情）と作り直した文を必ず書く。`make_vNNN.py` は、文が書かれていない強調を字幕の文字で埋めず止める（`tools/kyocho_check.py` の `require_texts`）
  2. `cuts_plan_vNNN.py`・`cut_vNNN.py`：カット（CUTS はフレーム番号、TEXT_FIX で字幕の文字の直し）
  3. `build_vNNN.py`：土台の XML
  4. `_work/place*.py`：Premiere で BGM・画像・素材を置く（ExtendScript でしかできない所）
  5. `make_vNNN.py`：.prproj を書き換える（`Library` で型IDから複製、`tools/native_prproj.py`）
     - make の後・検査の前に、本編の締め（「ということで今回は」など）の頭のつなぎ目へ Premiere Composer の Pan を付ける（毎回。`02` の transitions.closing_pan）：Premiere で Composer のパネルを一度開いてから `python3 tools/premiere_case/pan.py --proj … --seq … --at <つなぎ目の秒>`。make をやり直したら、もう一度
  6. `tools/premiere_case/finish.py`：Premiere で開いて画像の書き出し（ディゾルブは 5 の make で書く。2026-10-03 から）。組み立てたら `tools/premiere_case/close.py --record` で、AI の最後の組み立ての保存時刻と md5 を記録しておく（閉じる前の確かめに使う）
  - 実例：`tools/case_template/1027_v003/v003/`（一番新しい雛形）
- 置く位置・長さはフレームの整数倍。保存の前に `check_binaries()` を通す
- 土台の XML で日本語を含むパスは、percent-encode した file URI にする
- ファイルを作り直す前に、Premiere で開いている同じ版は保存せずに閉じる。閉じる前に、.prproj の保存時刻と中身が AI の最後の組み立てと同じか・自動保存に新しいものが無いかを確かめる（`tools/premiere_case/close.py`。違えば閉じずに止まる）。違えば、ユーザーが直している：閉じずに `tools/diff_user_edits.py` で直しを読み取り、工程12 のとおり意図を言葉にして OK をもらってから作り直しに入れる（AI が作った版でも、ユーザーが開いて触った後はユーザーのもの）
- Premiere で開いている（開くかもしれない）プロジェクトが使う映像・画像は、名前を変えない・消さない・同じ名前で上書きしない。作り直したものは新しい名前（`overlay_r2.mov` など。`tools/zukai/make_zukai.py --name=auto`）で書き、組み立ての記録をその名前に向けて組み直す。古いファイルは案件を閉じるまで残す（Premiere は見失ったファイルを、別のフォルダの同じ名前のファイルにつなぎ直すことがある。環境設定 v004 で I06・I07・I13 が I11 の画像になった）
- 以前の方式（`telop_xml.py` のネイティブテロップ差し替え・PNG 字幕・見本だけ置いて手で入力・`telop_animate.py` で後から動きを付ける）は使わない。見本集に合う型が無い時は、ユーザーに相談する
