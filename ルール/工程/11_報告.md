# 11. 報告・確認を頼む

- 渡す前に、工程9 の「止める」検査が全部 0 であること。「知らせる」検査（カットの検査の一覧など）は、数と中身を `確認_vNNN.md` の「不足」に書いて渡す（2026-11-06）
- 順番：`確認_vNNN.md` を書く → 軽い mp4 を確認ページで小川さんに出す（見るかは小川さんが決める。待たない）→ 確かめ係（作った会話とは別の AI・1回だけ）→ 3種類だけ直す（書き出しは r2 まで）→ Addness のタスクを全部読み、できている段を閉じ、閉じられない段に理由を書く → 小川さんに頼む（2026-11-06）
- 確かめ係が見るのも、渡す前に直すのも、次の3種類だけ。①見る人が気づく物（話がつながらない・字幕や部品が隠れる・画面と話が食い違う・字幕と声が違う）②事実や数字の違い（強調・説明・図解の文が話した言葉と食い違うのも含む）③実名などの個人情報。ほかの指摘は直さず、`確認_vNNN.md` の「不足」に一覧で書いて渡す
- 直しでカットを変える時は、描き直す図解の数と見込みの時間を先に出す。見込みが30分を超える時は直さず「不足」に書き、小川さんに決めてもらう
- `確認_vNNN.md` に時刻を3つ書く：依頼を受けた時刻・最初に mp4 を出した時刻・渡した時刻。小川さんの指摘の数も書く（ルールや道具を直すほど減っているかを、動画をまたいで見る）
- 「通った確認／不足／未確認／成果物の場所／次の作業」の形で `確認_vNNN.md` に書き、チャットで伝える
- 版・シーケンス名と、次を伝えて「確認お願いします」
  - 見てほしい時刻：強調＋SE、図解、BGM 停止、カットのつなぎ目、直した所
  - **言い直した強調テロップの一覧**（時刻・種類・話した言葉→出した文）。意味が変わっていないか見てもらう
  - **足した説明の一覧**（※・↑の一言・（ ）の補い・ツッコミ・「〇〇とは」の板。時刻・足した言葉・なぜ）。意味が変わっていないか見てもらう
  - **切った話の塊の一覧**（時刻・秒・中身・理由・前の一文 → 後の一文）。おすすめどおりに切ってあるので、「戻して」と言える形で見せる
  - 問いの札で文字を小さくした所（85%まで・それより小さく）
  - **聴いてほしい時刻**：カットのつなぎ目、BGM・SE の音量、BGM を止めた所
  - 入れた図解の一覧（時刻・型・なぜ）と画像
  - 直した音声認識の誤り、仮に決めた話者
  - 未確認点
- ユーザーが聴いて問題ないと言うまでは「未聴取」と書く
