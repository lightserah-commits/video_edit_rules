- 対象：同じチャンネル（みかみ）の公開動画で、実演の回の2本。小川さんがダウンロード（720p・29.97fps）
  - 「【実演】Claude完全攻略！基礎から神機能まで徹底解説。」（44.2分。以下「完全攻略」。小川さんの指定 17:57）
  - 「【実演】Claude Coworkで業務全自動化する方法の基礎講座。」（24.5分。以下「Cowork」。小川さんの指定 20:27）
- 比べた相手：お手本1本目（AI使いこなす習慣7選。40分）・2本目（AI時代に消える仕事残る仕事。シーケンス「冒頭」28.6分・59.94fps。「後半」は同じ内容の別の版）、astra の AI 版 v006（自動保存 18:14）・小川さんが直した v006（19:57）、ワークの完全解説の AI 版 v003・公開版
- 音は再生していない。波形と文字起こしの数字、書き出した画像だけを使った
- 道具は `実例/実演お手本/scripts/`（データの置き場 `~/Downloads/お手本_実演/analysis/` で動かす。読み取り `ocr/`・コマ `frames/`・切り抜き画像 `sheets/`・結果の JSON もそこ）。新しい完成動画をもらったら同じ手順で比べる
  - `run_ocr.sh`：0.5秒ごとの画面を Mac の文字認識で読む → `ocr/`（2本で8,248枚）
  - `telops.py`：同じ位置に同じ文字が続く間を1つのテロップにまとめ、色（赤・黄・青・白・黒の割合）を付ける → `telops_<名前>.json`
  - `classify.py`：位置・大きさ・色で種類に分け、種類ごとの切り抜きを並べる → `telops_<名前>_kind.json`、`sheets/`
  - `emph_timing.py`：テロップが出たコマ（30fps）と、書いた最初の言葉が聞こえ始める瞬間（文字起こし＋波形）の差。2行のテロップの2行目は除く → `timing_<名前>.json`
  - `voice_gaps.py`：波形で声の間を測る。`words_timeline.py`・`tempo.py`：完成版のタイムラインに置き直した語で測る
  - `asr_<名前>.json`：完成版の音の文字起こし（mlx_whisper large-v3-turbo。BGM 入りなので語の時刻は粗い）
- 測り方の誤差：ふつうの字幕でも「書いた最初の言葉より0.2秒以上早い」が6〜9%出る（字幕は本来、声と同時に出る）。これより小さい差は誤差と見る

## 3. 強調の文字（変更案 B）

- 主語と述語を残し、口癖だけを削る。抜けた助詞は足す
  - 「ClaudeCoworkの特徴はプラグインが多い」 ← 声「クロードコワークの特徴はやっぱプラグインがめっちゃある」
  - 「エグい格差が広がる」 ← 声「えぐい格差広がるよ」
  - 「自社で使うLPも／Claudeで作っている」 ← 声「自社で使うLPとかも一撃でクロードで作る」
- ぼんやりした言い方は、具体的な一文に直す（青い帯）
