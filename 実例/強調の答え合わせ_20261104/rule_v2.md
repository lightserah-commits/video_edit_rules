# 1. みかみCHの強調を、するか・種類・型まで決める

## 強調は2種類ある（中身で分ける）

| 種類 | 何のため | 例 | 型（色・書体） |
|---|---|---|---|
| 意味の強調 | 内容の核を残す | 結論・断言・原則・成果・要点・事実・キーワード・案内 | 温度で選ぶ。強調赤黄・基本テロップ赤・ゴージャス金／青が多い。冷めた言い方ならシュール |
| 感情の強調 | 話の温度を変えて飽きさせない | 褒め・肯定・喜び・驚き・ツッコミ・皮肉・本音・呆れ・笑い・短い反応 | 温度で選ぶ。プラスならゴージャス青・金、叫びなら強調赤黄、冷めならシュール、否定ならツッコミ、笑いならヒラギノ白シャドウ、短い反応なら白テキ |

- 種類は中身で決める。型（パターン）からは決めない。同じ型を両方に使ってよい
- 種類で文言の作り方が変わる（下の2）
- 大事な内容ではないが感情が動いた一言（「さすがですね」「楽勝ですね」「簡単やん！」「いい質問だね」）は強調してよい（強調の約3分の1はこちら）
- ただし「感情が動いた」根拠は発話そのものにあること。声のトーン・言い方・語尾（「〜やん！」「w」「…？」）、前後の流れ（ボケ→ツッコミ、フリ→オチ）で判断する。**件数を埋めるための強調はしない**

## 先に探す物

- **話した人が短く言い切った所を先に探す**。お手本の強調は、半分が11字以下、8割が16字以内。話した言葉のまま短く言えている所を強調にする（「全然違う」「解けたら解く意味ない」「人間の方が強い」「わかってないのが一番危ない」「多少攻めないといけない」）
- **説明を要約して強調を作らない**。話の要点でも、話した人が短く言い切っていない所は通常字幕のまま。長い説明をまとめた一文を自分で作らない
- **冷めた言い方の一言を見落とさない**。お手本の強調の半分近くはシュール。低い温度で言い切る一言、ぼやき、身もふたもない現実、例え話の中の情けないセリフ（「僕のチームで起こってます」「工場で働かされるだけ」「いや俺頭悪いから無理だわ」）

## 決め方

字幕1枚ずつで決めない。候補の**前の2〜3文と後ろの1〜2文まで読み**、同じ話が字幕数枚にまたがる時は1か所として扱う。

1. 下の質問1・2（装飾しない・代弁）に答える
2. 強調するなら、種類を中身で決める。残す核を一文で言えない所は強調しない
3. 質問3〜9で型（温度）を選ぶ。種類はここで選んだ型では決まらない（冷めた言い方の結論は、意味の強調でシュール。「いい質問だね」は、感情の強調でゴージャス青）
4. 文言は下の2で作る

最初に「はい」になったところで決める。

1. **装飾しない条件に当たるか？** → 当たれば NONE
   - つなぎ・前置き・相づち・言い直し・具体例の説明の途中
   - 代名詞だけ（「彼」「それ」）、フィラー
   - 直前に強調した一言の言い換え・続き（同じネタで強調は1回。下の「1ネタ1発」）
   - 文字起こしが怪しい字幕（大きく出すと誤りが目立つ）。通常字幕も直せていなければ、要確認として報告する
   - 字幕の一部だけが強調したい言葉で、残りが説明の続きの字幕。ただし、核を一文に作り直して1枚にできる時はそうする
2. **誰かになりきって言っているか？**（視聴者・部下・AI・世の中の人のセリフや心の声。「〜ってなる」「〜って言う」「〜って思う」の中身、口調や声色が変わる）→ **P16 代弁**
   - わざと分かっていない人・大げさな人を演じて笑いにする → アホなふり（黒帯＋白い明朝。相手役は左右反転）
   - 自分の頼みと AI の返事を1人で演じて、AI とのやり取りを再現する → 1人2役にせず、三上さんのアイコンと AI のチャットの図解
   - よくいる人が言いそうなセリフで、みんなの常識を引き出す → 常識を引っ張る（白背景のセリフの札＋役名ラベル＋役のイラスト）
   - AI に声で頼んでいる間・打ち込みながら読み上げている間は、強調ではなく **P17**（この動画は画面が無いので当たらない見込み）
3. **強く否定・ダメ出し・鋭い指摘をしているか？**（「バカか」「〜ないですか？」「罪」「いやー！」）→ **P06**
4. **冷めた本音・皮肉・身もふたもない現実・残念な結末か？**（低いテンションで言い切る。皮肉の前振りも）→ **P04**
5. **笑い・呆れ・ボケか？**（「w」、繰り返しギャグ、呆れ）→ **P05**
6. **1〜数語の素朴な反応・困惑か？**（「くろーどこーど…？」「視聴者ついていけてないです…」）→ **P07**
7. **力強い言い切り・断言・結論・宣言か？ 驚き・興奮の叫び（「すごくない？」「やばい」「来た来た」「簡単やん！」）か？ 完了の一言か？** → **P01**（強調赤黄）。良い話でも、言い切っている・叫んでいるならこれ
8. **数字で示す成果・見出しか？**（「2億940万円」「並列作業で生産性が常人の15倍」「無料で使えます」）→ **P02**（金）。**相手を認める・肯定する一言か、締めの名言・世界が変わる級の大きな話か？**（「いい質問だね」「その通り!」「そしたら世界が変わる」）→ **P03**（青）。ゴージャスは山場の色なので、ふつうの「良い話・できること」には使わない
9. **覚えてほしい原則の一文で、話した言葉がそのまま短い一文になっていて、上のどれでもないか？** → **P08**（赤）。ボードにする価値があれば **P09**
10. **一瞬だけ引っかけたい一言か？**（「マジで」「これ絶対」）→ 通常字幕のまま **ピピだけ**（-9.8dB）
11. どれでもない → **NONE**

- 聞き手の発言も同じ質問で判定する。聞き手のリアクション（「適応しないと！！！」「自分で見つけれる人の方が珍しくないですか？」「いやー！」）も強調する。新機能の説明など、情報の核になる聞き手の一言も強調する（例「最近エージェント機能とかが追加された」を赤で）
- 「赤で強調」と言われたら強調赤黄（T147）

## 型の選び方（温度・向き → 型）

数はお手本2本の件数。

| 温度・向き | 意味の強調のとき | 感情の強調のとき |
|---|---|---|
| 決め・断言・叫び・完了 | 強調赤黄 T147（37）「0か1かの仕事は 絶対AIが有利」「そいつらが金持ちになる」「本気で使うならOpus一択」 | 強調赤黄（4）「これ！！！」「簡単やん！」。驚き・興奮（すごい・やばい・来た）もここ |
| 要点の一文・手順・情報（字幕の位置の赤い一文） | 基本テロップ赤 T153（25）「構造だけ覚えとけば変にはならん」「パソコンは閉じちゃダメ」「これが真ん中のSonnetです」 | ― |
| 数字の成果・大きな成果・見出し | ゴージャス金 T184（18）「AIは必ずわかってくれる」「2億940万円」 | ゴージャス金（2）「タスク化完了」。喜び・興奮の一言は金にしない（赤黄か白シャドウ） |
| 相手を認める・締めの名言・大きな話 | ゴージャス青 T175（12）「その環境に最も適応したものだ」「そしたら世界が変わる」 | ゴージャス青（6）「いい質問だね」「その通り!」「セットアップ完了」 |
| 冷め（結論・警告／本音・皮肉・呆れ） | シュール T010（20）「工場で働かされるだけ」「わかってないのが 一番危ない」 | シュール（23）「Webサイトで飯食えんからね」「本当にここからだと 思ってないよね」 |
| 強い否定 | ツッコミ T086（2）「守りしかやらんヤツは無理」 | ツッコミ（12）「なんもわかっとらんやん」「どうでもいいじゃん」 |
| 軽い・笑い | ヒラギノ白シャドウ T020（8）「これが成り立つのは最初だけ」「100%AIでいい」 | ヒラギノ白シャドウ（10）「全部じゃんw」「慣れ慣れ慣れ慣れ」 |
| 短い反応・編集者のツッコミ | 白テキ T023（3） | 白テキ（8）「くろーどこーど…？」「笑いすぎ」 |

- **赤い系が強調の中心**：字幕の位置の赤い一文（基本テロップ赤 T153。言い切るほど強くないが覚えてほしい要点の一文）・赤黄・ツッコミ。1分あたり赤い系が約5、ゴージャス（金・青）は約0.5（約8〜10：1）。ゴージャスは強調の18%ほど
- **ネガティブな話はシュール**：お金を取られた・被害・損の話は、数字が核でもシュール T010＋鈴しゃん（P04。引き・BGM 停止のセット）にする。決め（赤黄＋太鼓）にしない
- **見直しのきっかけ**：ゴージャスが赤い系の3分の1を超える・感情の強調に金が多い・シュールが1割を切る時は、選び方がずれていないか見直す（`tools/kyocho_check.py --csv` の「# 型の割合」と「# 見直す」。数を合わせるためではない）

## ボケとツッコミを拾う

- 三上さんのボケ（自慢・大げさ・とぼけ・突飛なたとえ。例「アフリカにでも行けばいいじゃん」「俺は頭がいいのよ 自分で言うのもなんだけど」）と、聞き手が付いていけない・ツッコむ一言（例「つまりどういうことなんですかね？」「そんな脳筋みたいな感じなんすね」）は、**白テキ（P07）＋ポカン**で拾う。言ったまま（後ろのぼかしは削る）。聞き手の字幕なら寄りなし。前に溜め（0.35秒）
- 数を埋めるためには足さない（ボケ・ツッコミになっている所だけ）

## 1ネタ1発・連続の扱い

- 同じネタが字幕数枚に続くときは、**オチ（着地）の1枚だけ**に SE とズームを付ける。一文にまとめられる時は1枚にする
- **強調スタイルにした字幕には SE を付ける**。SE を鳴らさないなら、その字幕は強調スタイルにせず通常字幕のままにする
- 代弁（P16）でセリフが続くときは、黒帯（アホなふり）か白背景の札（常識を引っ張る）で見せ、SE は基本付けない。BGM は止めない
- 列挙（P11）だけは、項目ごとに同じ音（cursor1）を繰り返してよい
- 一文の一語だけを強調する部分強調もある（P06 の partial）
