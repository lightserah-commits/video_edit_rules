The user (小川さん) judges an edit by whether it "頭に入る" — whether a 偏差値40 viewer can watch it 脳死で (without thinking) and still follow it. On 2026-10-02 the user corrected: "ノーサウンドではなく脳死やな". The 2026-09-29 note "ノーサウンドで見れるかが大事" was a voice-input mishearing of "脳死で見れるかが大事". Do not frame checks as "音を消して分かるか"; frame them as "考えずに分かるか". The opening ~13 minutes matter most because that is where viewers drop off.

- Interviewer question plates (P11 問い) must not be summarized into noun phrases ("Astraの何がすごい？"). Write the question as asked: keep the subject and the condition ("三上さんが使ってみて Astraの何がすごいと思いますか？"). The reference video (お手本1本目) writes questions this way.
- When 三上さん changes his answer mid-thought, cut the earlier version and the listener's reaction to it. Keep only the final, settled version.
- Before building, read the whole edit in viewer order (subtitles + questions + emphasis + diagrams + cut points) and check that each item is understandable alone and connects to what comes before and after.
- Diagram labels need a subject and concrete content grounded in what was actually said, not shorthand like "Fable：手探り".
- The user's own fixes point the same way: explain jargon/implications with ※注釈・（補う言葉）・↑注釈 (the references do this; AI versions had almost none), keep the speaker's actual key word instead of paraphrasing it.
