## 人が使うとき

1. Premiereで `テロップ見本集.prproj` を開く
2. `型一覧.md` で使いたい型を探し、「見本集の位置」のタイムコードへ移動する
3. そのクリップをコピーして、自分のシーケンスに貼り付け、文字を打ち替える（エフェクトもアニメーションも一緒に付いてくる）

## AIが使うとき（`tools/reproduce.py`）

```python
from reproduce import Library
lib = Library("案件/v001/edit.prproj")        # 見本集プロジェクトのコピーの中で作業する
seq = lib.pj.sequence("編集シーケンス")
lib.add_telop(seq, "T001", "通常の字幕", start=12.3, duration=1.8, track="V6")
lib.add_effect(seq, "E001", start=20.0, duration=3.9, track="V5")
lib.add_se(seq, "S004", start=20.0, track="A4")
lib.save("案件/v002/edit.prproj")
```

- 見本の共有物（元クリップ・素材・保存スタイル）は見本集プロジェクトの中にあるので、**編集するシーケンスも見本集プロジェクトのコピーの中に置く**
- 文字レイヤーやランが複数ある型（ポイントボード、章見出し、1文字ずつ書式が違うタイトルなど）は、`lib.type_texts("T028")` で形を確認し、同じ形で文字を渡す
- **文字の大きさは自動で決まる**（`add_telop` の `size="auto"` が既定）。`../06_テロップの大きさ.yaml` の決まりで、新しい文を実際のフォントで測り、スタイルの基本の大きさで置いて、横幅が画面の90%を超えるなら縮める。5文字以下の短い一言はスタイルごとの倍率まで大きくする。決まった大きさと注意（「1行のままだと基本の大きさの◯%まで縮む。2行にする」など）は `lib.size_log` に残る
  - 代弁のアホなふり（誰かになりきって言う所。02 の P16）のセリフ T009 は `pattern="P16"` を渡す（小さめの114になる）
  - 見本の大きさのまま置くときは `size=None`、大きさを指定するときは数（例 `size=180`）
  - 06 の表にないテロップ（通常字幕・ポイントボード・章見出しなど）は見本の大きさのまま
- 保存時に `check_binaries()` で .prproj の決まり（共有バイナリの中身は1か所だけ）を確かめる。違反があると保存しない

## 作り方（作り直すとき）

```
python3 tools/type_catalog.py 完成.prproj --sequence 本編 --out 見本/分類
python3 tools/build_library.py --reference 完成.prproj --sequence 本編 --types 見本/分類/types.json --out 見本/テロップ見本集.prproj
python3 tools/make_type_list.py
python3 tools/verify_library.py --structure --library 見本/テロップ見本集.prproj --reference 完成.prproj --ref-sequence 本編 --out 見本/確認
python3 tools/verify_library.py --library 見本/テロップ見本集.prproj --reference 完成.prproj --ref-sequence 本編 --out 見本/確認
```

- `--structure` は Premiere を使わない構造チェック（`確認/構造チェック.json`）。見本ごとに、見本集の区間と元の同じ区間をクリップ単位で突き合わせ、長さ・文字・見た目と動きの指紋・音量・素材の頭と終わりの位置を比べる。元にだけあるクリップ（見本に入れていない周りのテロップや画像）は問題に数えない（場面見本は数える）
- `--structure` なしは Premiere で画像を書き出して比べる。先に `python3 tools/premiere_bridge.py status` で Premiere とブリッジのパネルが1つずつか確かめる（2つ以上だと同じ命令が両方で実行されるので、ツールは止まる）。出力は `確認/並べ/<ID>.jpg`（元｜見本｜差）、`確認/一覧_<区画>_<番号>.jpg`、`確認/差分.json`
