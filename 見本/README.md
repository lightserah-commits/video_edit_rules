## 人が使うとき

1. Premiereで `テロップ見本集.prproj` を開く
2. `型一覧.md` で使いたい型を探し、「見本集の位置」のタイムコードへ移動する
3. そのクリップをコピーして、自分のシーケンスに貼り付け、文字を打ち替える（エフェクトもアニメーションも一緒に付いてくる）

## AIが使うとき（`tools/reproduce.py`）

```python
from reproduce import Library
lib = Library("案件/edit/v001/案件_v001.prproj")   # 部品集のコピー（build_parts.py --case-copy で作る）の中で作業する
seq = lib.pj.sequence("編集シーケンス")
lib.add_telop(seq, "T001", "通常の字幕", start=12.3, duration=1.8, track="V6")
lib.add_effect(seq, "E001", start=20.0, duration=3.9, track="V5")
lib.add_se(seq, "S004", start=20.0, track="A4")
lib.save("案件/edit/v002/案件_v002.prproj")
```

- 見本の共有物（元クリップ・素材・保存スタイル）は見本集・部品集のプロジェクトの中にあるので、**編集するシーケンスも部品集のコピーの中に置く**（見本の複製は、シーケンス「テロップ見本集」があるプロジェクトの中でだけ動く）
  - コピーは `python3 tools/build_parts.py --case-copy "<案件フォルダの絶対パス>/edit/v001/<案件>_v001.prproj"`（video_edit_rules で打つので絶対パスで書く）。素材をこの Mac の `素材/` と案件のフォルダから見た相対パスに向け直す（Air と iMac でユーザー名が違っても見つかる）。部品集が見本集より古い（`_元.json` の指紋が違う）・素材が欠けている・`素材/` の外を指す素材がある・`video_edit_rules` の中に作ろうとした時は、何も書かずに止まる
  - 部品集には場面見本 D・背景の映像が無く、プロジェクトパネルにも BGM・イラストの素材が無い（SE は ④SE のビン、型が使う画像2つ＝T167 の画像とテロップベース簡易.psd はある）。人が案件のプロジェクトで BGM・イラストを足す時は `../素材/` から読み込む
- 文字レイヤーやランが複数ある型（ポイントボード、章見出し、1文字ずつ書式が違うタイトルなど）は、`lib.type_texts("T028")` で形を確認し、同じ形で文字を渡す
- **文字の大きさは自動で決まる**（`add_telop` の `size="auto"` が既定）。`../06_テロップの大きさ.yaml` の決まりで、新しい文を実際のフォントで測り、スタイルの基本の大きさで置いて、横幅が画面の90%を超えるなら縮める。5文字以下の短い一言はスタイルごとの倍率まで大きくする。決まった大きさと注意（「1行のままだと基本の大きさの◯%まで縮む。2行にする」など）は `lib.size_log` に残る
  - 代弁のアホなふり（誰かになりきって言う所。02 の P16）のセリフ T009 は `pattern="P16"` を渡す（小さめの114になる）
  - 見本の大きさのまま置くときは `size=None`、大きさを指定するときは数（例 `size=180`）
  - 06 の表にないテロップ（通常字幕・ポイントボード・章見出しなど）は見本の大きさのまま
- 保存時に `check_binaries()` で .prproj の決まり（共有バイナリの中身は1か所だけ）を確かめる。違反があると保存しない

## 決まりごと

- **フォント**：このMacの Premiere で使えないフォントは、見本集では置き換えてある（`tools/font_fix.py`。HiraKakuStdN-W8 → HiraginoSans-W8、Corporate-Logo-Rounded-Bold-ver3 → HiraMaruProN-W4、YuGothic-Bold → HiraginoSans-W6）。Premiere で開いても「フォントを解決」は出ない（確認済み）
  - 新しい素材やプロジェクトから型を足した時は、見本集にも `python3 tools/font_fix.py 入力.prproj 出力.prproj` を通す（無いフォントの表は font_fix.py の TABLE。増えたら足す）。案件では検査で `--scan` が0件か見るだけ
- **背景の映像**：見本集の見本の背景は、元の素材（`~/Desktop/video_edit_rules/完成版/コピー_みかみさんCH0726_1/` の IMG_1063 など）を参照している。素材を移動するとオフラインになる。部品集は背景の映像を持たず、SE・画像は `../素材/` を指すので、完成版の素材が無い Mac でも使える
- **型の粒度**：見た目（書式・サイズ・位置）とアニメーションが1つでも違えば別の型。完成版はサイズや位置を1本ずつ調整したものが多く、198型のうち160型は1回だけ使われた一点物
- タイトルの位置など、型をどう使うかの決まりは `../02_演出パターン.yaml`（右上タイトルは 02 の titles）

## 型を足すとき（区画 F・G・H でやった手順）

1. 足す前の見本集・目次・types.json・型一覧を `_backup/`（版の番号つき）に控える
2. 取り込み元は、フォント名を置き換えたコピーを使う（「フォントを解決」を出さないため。`tools/font_fix.py`）
3. 部品を見本集へ写す
   - 取り込み元が別のプロジェクトの時：見本集のコピーを Premiere で開き、取り込み元のシーケンスを `importSequences` で取り込んで保存 → スクリプトで「テロップ見本集」のシーケンスへ複製（区画F・G）
   - 案件のプロジェクトが見本集のコピー由来で参照が同じ時：Premiere を使わず、部品一式（スタイル・素材・元のクリップ。文字のデータは見本集に無い分だけ中身ごと）を写してよい（区画H）
4. 目次・`分類/types.json` に足し、`python3 tools/make_type_list.py` で型一覧を作り直す
5. 取り込みで増えた不要なシーケンス・リンク切れの素材を消して保存する（見本集のシーケンスが使っていないことを確かめてから）
6. 確かめる：既存の見本がクリップ単位で元と同じ（`verify_library.py --structure`）、新しい型から文字を変えて複製できる（`Library.add_telop`）、フォントの置き換え漏れ0
7. このファイルの区画の表に足し、ユーザーに見せて確認をもらう。使い方を決めたルールのファイル（02・07・09 など）にも型IDを書く
8. `python3 tools/build_parts.py` で部品集を作り直す（見本集・目次・types.json を直したら毎回。作り直さないと `--case-copy` が「部品集が古い」で止まる）。見本の型が使う素材が `../素材/` に無いと止まるので、その時は `素材/` に足す（ユーザーに確認してから）。S003 の `キーン（ポイント）_002.wav` は中身を比べてから `素材/SE/キーン（ポイント）.wav` に向けるので、作り直すには `~/Desktop/video_edit_rules/完成版/コピー_みかみさんCH0726_1/` にその元のファイルが要る（無いと止まる）。中身が同じなら作り直してもファイルは同じになる（git に差が出ない）

各区画で使ったスクリプトの場所と数（クリップ数の変化など）は `../変更履歴.md`。

## 作り方（作り直すとき）

```
python3 tools/type_catalog.py 完成.prproj --sequence 本編 --out 見本/分類
python3 tools/build_library.py --reference 完成.prproj --sequence 本編 --types 見本/分類/types.json --out 見本/テロップ見本集.prproj
python3 tools/make_type_list.py
python3 tools/verify_library.py --structure --library 見本/テロップ見本集.prproj --reference 完成.prproj --ref-sequence 本編 --out 見本/確認
python3 tools/verify_library.py --library 見本/テロップ見本集.prproj --reference 完成.prproj --ref-sequence 本編 --out 見本/確認
```

- `--structure` は Premiere を使わない構造チェック（`確認/構造チェック.json`）。見本ごとに、見本集の区間と元の同じ区間をクリップ単位で突き合わせ、長さ・文字・見た目と動きの指紋・音量・素材の頭と終わりの位置を比べる。元にだけあるクリップ（見本に入れていない周りのテロップや画像）は問題に数えない（場面見本は数える）
- `--structure` なしは Premiere で画像を書き出して比べる。先に `python3 tools/premiere_bridge.py status` で Premiere とブリッジのパネルが1つずつか確かめる（2つ以上だと同じ命令が両方で実行されるので、ツールは止まる）。出力は `確認/並べ/<ID>.jpg`（元｜見本｜差）、`確認/一覧_<区画>_<番号>.jpg`、`確認/差分.json`
- 文字データの解析器（`Flat`）は、このフォルダの外（`~/Downloads/林社長コラボ_v007_颯太引継ぎ_20260922_draft/.../プロマネ静的解析.py`）から読み込んでいる。移動・削除すると type_catalog・構造チェックが動かない
